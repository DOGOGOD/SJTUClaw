# 课程报告结构与质量检查

仅在选择报告结构或执行终检时读取本文件。先使用对应类型的结构，再执行通用检查；不要把所有章节强行塞进同一份报告。

## 按报告类型选择结构

### 课程小论文

1. 问题与中心论点
2. 必要背景或概念界定
3. 由证据支撑的 2–4 个子论点
4. 反方观点、限制或适用边界
5. 回应问题的结论

### 实验报告

1. 实验目的与可检验问题
2. 原理、条件与材料
3. 实际执行的方法和步骤
4. 原始数据、处理方法与结果
5. 误差、不确定性与讨论
6. 与实验目的对应的结论

缺少真实步骤或数据时，保留 `[待补：具体内容]`，不得生成示例数值冒充实验结果。

### 读书报告

1. 书目与阅读范围
2. 作者的核心问题和主张
3. 关键论证、概念或文本证据
4. 有依据的评价、质疑或联系
5. 总结与仍待讨论的问题

不要虚构阅读进度、章节细节、页码或原文引语。

### 课程学习总结 / 反思报告

1. 课程内容与个人目标
2. 具体知识或能力变化
3. 由课堂任务、项目或材料支持的例子
4. 尚存不足及其原因
5. 可执行的后续计划

没有用户经历材料时，使用 `[待补：个人经历/课堂案例]`，不要代写虚构体验。

## 通用终检

### 任务匹配

- [ ] 标题和中心论点直接回应作业题目。
- [ ] 报告类型、篇幅、章节和格式符合已知要求。
- [ ] 每个正文小节都服务于中心论点，没有离题段落。

### 论证与证据

- [ ] 每个关键主张都有证据或清楚标记为分析/推断。
- [ ] 证据之后有解释，不只罗列材料。
- [ ] 冲突证据、限制和反例没有被刻意省略。
- [ ] 结论回答了引言提出的问题，没有引入未经论证的新观点。

### 来源与真实性

- [ ] 参考资料均被实际读取或核验，正文与列表相互对应。
- [ ] 作者、标题、日期、页码、链接和 DOI 没有凭空补全。
- [ ] 数据、实验过程、阅读经历和个人体验均来自真实材料。
- [ ] 未核验内容和材料缺口已集中标记。

### 表达与交付

- [ ] 段落有明确主张，衔接自然，术语和时态一致。
- [ ] 删除空泛套话、重复内容和为凑字数添加的段落。
- [ ] 字数为已核对的精确值，或明确标注为近似值。
- [ ] 保存路径和写入结果已核实；未成功写入时没有声称已保存。
