# Course Report

**铁律：绝不编造来源、数据、实验过程或阅读经历；事实与引用只来自用户提供或实际核验过的材料。**

## 执行清单

- [ ] **1. 确认作业约束 ⚠️ REQUIRED**
  - 提取报告类型、课程名称、题目/研究问题、字数、格式、受众、截止要求、引用规范、参考材料和交付方式。
  - 主题或任务要求缺失时先询问；实验数据、指定文本等决定报告真实性的信息缺失时不得代填。
  - 对非关键缺项采用合理默认值并在草稿前说明：普通课程小论文、中文、1500–2000 字、Markdown、在对话中交付草稿。

- [ ] **2. 读取要求和材料 ⚠️ REQUIRED**
  - 优先读取作业说明、评分标准、教师模板，再读取正文材料。
  - 为每项关键事实、数据、观点和引语记录实际来源。
  - 材料不足时，缩小论断、标注 `[待补材料]`，或说明需要补充什么；不得用虚构参考文献填空。
  - 涉及当前事实或精确数据时，仅使用实际检索并核验过的来源。

- [ ] **3. 选择类型结构并拟定论点 ⚠️ REQUIRED**
  - 当报告类型不是普通课程小论文，或需要终检时，按需读取 `references/checklist.md`。
  - 用一句话写出中心问题和中心结论；每个正文小节只承担一个子论点。
  - 先建立“论点 → 证据 → 解释 → 与主旨的关系”，再开始成稿。
  - 结构服从作业类型，不机械套用摘要、引言、三段正文、结论。

- [ ] **4. 撰写可审阅草稿 ⚠️ REQUIRED**
  - 区分材料事实、作者观点和报告撰写者的分析。
  - 段落以明确主张开头，用证据和解释支撑，结尾衔接下一段。
  - 直接引语保持必要且简短；不能确认原文时改为转述并保留来源。
  - 仅列出实际使用过的参考资料；不虚构作者、标题、页码、DOI 或访问日期。
  - 实验报告不得补造实验步骤、观测值、图表或误差结果；缺失处使用明确占位说明。

- [ ] **5. 控制篇幅与一致性**
  - 按信息价值分配篇幅，避免各节平均分配。
  - 有可用计数工具时核对字数；否则给出近似值，不声称精确达标。
  - 统一标题层级、术语、时态、数字单位和引用格式。

- [ ] **6. 执行质量核验 ⚠️ REQUIRED**
  - 使用 `references/checklist.md` 的对应报告类型与通用检查项。
  - 逐项确认题目回应、论证闭环、来源真实性、字数和格式。
  - 将无法核验或仍需用户补充的内容集中列为“待确认事项”。

- [ ] **7. 交付或保存**
  - 先说明采用的假设、材料范围和待确认项，再给出草稿。
  - 用户未要求保存时，直接在对话中交付，不擅自创建文件。
  - 用户要求保存但未给路径时，使用基于题目的安全相对文件名，如 `题目-course-report.md`。
  - 写入前避免意外覆盖现有文件；写入后仅在工具返回成功时报告保存完成。

## 默认输出骨架

```markdown
# 报告标题

> 草稿说明：报告类型、采用的假设、材料范围、待确认项

## 摘要（仅在作业要求时）
概括问题、方法/分析路径和主要结论。

## 引言
交代问题、意义、范围和中心论点。

## 正文小节
以论点组织证据与分析，不按材料顺序堆叠。

## 结论
直接回应中心问题，说明限制或后续思考。

## 参考资料
仅列实际使用并可核验的来源。
```

## 禁止事项

- 不承诺“规避查重”“绕过 AI 检测”或代替用户完成被禁止的学术行为。
- 不用空泛套话、虚构个人经历或未经材料支持的“深刻体会”填充篇幅。
- 不把参考资料列表当作装饰；正文使用的来源与列表必须对应。
- 不把草稿称为最终定稿，也不隐瞒材料缺口和未核验事实。
